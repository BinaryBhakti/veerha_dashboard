Quotations

Two screens. The live product has a single quotes list and no detail view — a quote is the thing a customer actually receives, so it earns a record of its own.

6 Quotations index /quotes A1 · populated

Designed, not reproduced. The live app has only ever rendered this screen empty — five zero KPIs, five zero tab counts, then an empty table — so row density, status styling and column formatting have no evidence behind them at all. Three changes carry the redesign. There was a KPI strip and a status tab strip, two filters whose vocabularies did not line up (the cards offered Awaiting send and Going cold, the tabs offered Drafts and Awaiting reply, and neither set contained the other); here one row of scope tiles carries the whole vocabulary and the two money figures sit below it as a summary, not as a second set of filters. Validity and Proforma now state their unit — a date with the days left on it, and a proforma number or the fact that none has been raised. And the header row is one component again: every column label is set the same way.
