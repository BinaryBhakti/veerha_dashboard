37Properties /propertiesA1 · index · folds /inventory

Two live screens fold into this one. /properties and /inventory — labelled "Shared Resources" in the live sidebar — are the same index with a different noun, so the noun becomes a switch in the action cluster instead of a second page. The live subtitle runs location · entity · timestamp together into one ungrammatical string; here it is three columns — where it is, what Veerha reads, when it last read it. The read-only promise is promoted out of the grey description into a banner, because it is the most load-bearing sentence on the page.

37bProperties — shared resources /inventoryA1 · the folded noun

39Pricing /pricingA5 · config · populated

The live page is empty in production, so this populated state is the first time the price list has ever been drawn — column layout, the active column the live page declares but never renders, and the sync telemetry it has none of. Four things are fixed on principle: the unlabelled A:F range is labelled and says what it excludes, the API key is masked, Save outranks Sync now, and the destructive replace announces itself before you pick a file rather than after.
