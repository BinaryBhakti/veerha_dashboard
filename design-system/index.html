A system, not a set of screens.

Veerha brings AI employees, customer conversations and business operations into one workspace. The interface has to make that manageable — and it has to answer five questions fast: what happened, what did Veerha do, why, what needs my attention, and what happens next. This document defines the language that answers them consistently, so new screens can be added without the product drifting.

02

The four principles

Every decision in this system traces back to one of these. When a choice is unclear, the principle decides it.

Clarity before personality

This is software a sales team keeps open eight hours a day. Hierarchy, density and scannability come first; character comes after, and never at their expense.

Humans stay in the loop

AI can move work forward, but the product must always show when it is acting, waiting, asking for approval, or handing control back to a person.

Every claim shows its evidence

A recommendation the user cannot interrogate is a recommendation they will not trust. Insight, then evidence, then action — in that order, every time.

Repeated work uses shared patterns

103 routes in the product collapse to 11 layouts. A screen that invents its own structure is a screen that will drift — and one more thing to maintain.

03

How to read this

Components are shown with every state drawn as its own frame — default, hover, focus, selected, disabled, loading, error — the way a Figma library shows variants. Nothing is hidden behind an interaction, so everything can be reviewed by scrolling.

ConventionMeaning
--token-nameA value from system/tokens.css. Components never carry raw hex or raw pixel radii.
.v-componentThe product class. Everything is v- prefixed to prevent collisions.
.is-stateA forced state, used so documentation can show what a hover or error looks like without hovering.
Scope of this version. Light mode, desktop. Tablet and mobile layouts and the dark theme are the next phase — the tokens they will need are already declared, so nothing has to be retrofitted. The 77-screen inventory itself follows once this language is approved.
